## Detailed description

Read GitHub in your language.

GitHub Translate turns GitHub's built-in AI translation into a
one-click page translation for issues, pull requests, and repository
READMEs — without API keys, accounts, or sending your text to a third
party. Translation runs on your device through Chrome's built-in
Translator API.

What it translates:

- Issue details: titles, descriptions, and comments
- Issue and pull request lists: row titles
- Pull request conversation tabs
- Repository overview pages: the rendered README

Features:

- 39 languages via Chrome's built-in Translator (Chrome 138+, desktop)
- Auto-translate on page load, or translate on demand from the toolbar
  popup
- Per-area control: translate titles, bodies & comments, and list
  titles separately for issues, pull requests, and READMEs
- Text already written in your language is detected and left untouched
- Optional input helper: type in your language and get text ready to
  paste into a GitHub comment box (translates in the reverse direction)

Privacy: the extension stores only your settings (chrome.storage.sync),
makes no network requests of its own, and never collects or shares
data. See the privacy policy for details.
